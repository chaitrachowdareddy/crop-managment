Beginner's Guide to Setup MySQL

You can use either standard MySQL Community Server, MySQL Workbench, or XAMPP (phpMyAdmin).

  • If using XAMPP: Open XAMPP Control Panel and click Start next to MySQL.
  • If using MySQL Server: Ensure the Windows MySQL service is running.

Open Command Prompt in the project folder and run:

mysql -u root -p < database/schema.sql
mysql -u root -p < database/sample_data.sql

Enter your MySQL root password when prompted.

  1. Open phpMyAdmin (http://localhost/phpmyadmin) or MySQL Workbench.
  2. Click on the Import tab.
  3. Choose database/schema.sql and click Go / Execute.
  4. Choose database/sample_data.sql and click Go / Execute.

Open the .env file in this folder and update DB_PASSWORD to your MySQL password:

DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_actual_password_here
DB_NAME=crop_supply_chain
