Relational Architecture

Completely designed with 15 normalized tables (3NF), Foreign Key relationships with cascade rules, and check constraints to guarantee database integrity.

  • One-to-Many & Many-to-Many
  • Referential Integrity Constraints
  • Domain & Check Constraints
Advanced SQL Features

Demonstrates Stored Procedures, automated SQL Triggers for inventory calculation, complex multi-table JOINs, Subqueries, and Aggregate functions.

  • SQL Triggers & Procedures
  • Database Views (Reporting)
  • GROUP BY & HAVING Clauses
Secure Parameterized SQL

Prevents SQL Injection attacks across all CRUD forms using parameterized prepared queries. Validates phone numbers, positive prices, and stock limits.

  • Parameterized SQL Queries
  • Client & Server Validation
